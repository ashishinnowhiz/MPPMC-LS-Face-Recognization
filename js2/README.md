# Evaluation System Refactor

This package contains a secure and modular ES6 refactor starter structure for your old `eval.js`.

## Features
- Secure API wrapper
- CSRF-ready requests
- XSS protection hooks
- Async/Await architecture
- Centralized state management
- Modular structure
- Duplicate-save prevention
- Event delegation
- Error handling
- Modern ES6 syntax

## Folder Structure

/core
- api.js
- state.js
- validation.js

/modules
- canvas.js
- save.js
- ui.js

/main.js

## Recommended Libraries
- DOMPurify
- SweetAlert2

## Usage
Import `main.js` into your page and initialize the application.
